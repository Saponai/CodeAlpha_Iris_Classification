# Iris Flower Classification

## Project Overview
This project was completed as part of the CodeAlpha Data Science Internship.

The goal is to classify Iris flowers into three species using sepal and petal measurements.

## Tools and Technologies
"Python
"Pandas
"Matplotlib
"Seaborn
"Scikit-learn

## Methodology
1. Data exploration and visualization
2. Feature selection
3. Train-test split
4. Random Forest model training
5. Model evaluation using accuracy, precision, recall, F1-score, and a confusion matrix

## Results
The model achieved **90% accuracy** on the test dataset, correctly classifying 27 out of 30 flowers.

Iris-setosa was classified correctly in all test cases, while some confusion occurred between Iris-versicolor and Iris-virginica.

## Conclusion
The results demonstrate that sepal and petal measurements can be used to classify Iris species. The project provided practical experience with exploratory data analysis and supervised machine learning.
